title: "Agent types"
description: "Prompt agents, static bots, and workflow agents, and how to choose a model preset."
---

Sayvy AI has three agent types. Pick one when you create the agent. The type decides how the agent works out what to say next.

| | Prompt agent | Static bot | Workflow agent |
|---|---|---|---|
| How it decides | A language model follows your system prompt | Fixed rules you define | A graph of steps you draw |
| Good for | Open questions, support, sales, front desk | Simple menus and fixed answers | Scripted flows such as qualification or triage |
| Uses tools | Yes | No | Yes, in function steps |
| Variables like `{{name}}` | No | No | Yes |

## Prompt agent

You describe the job in a system prompt and the model handles the conversation. This is the quickest way to get a capable agent, and the right choice for most teams. It can use every built-in tool: knowledge base search, calendar booking, CRM updates, and handoff to a human.

## Static bot

A static bot replies with responses you set up ahead of time and no language model. Use it when every answer must be exactly the same each time.

## Workflow agent

A workflow agent follows a graph. Each step does one thing: greet, hold a conversation on one topic, call a function, transfer the call, pull values out of what was said, or branch on a condition. The model picks which path to take from the plain-language labels you put on each connection. Workflows come with starter templates for lead qualification, support triage, appointment requests, and FAQs with handoff.

## Model presets

Prompt and workflow agents run on a model preset. Gemini Flash is the default.

| Family | Presets | Notes |
|---|---|---|
| Gemini | Lite, Flash, Pro | Separate transcription, model, and speech steps |
| Gemini Live | Live, Live Reasoning | Speech-to-speech, with the lowest latency on calls |
| Sarvam | Lite, GLM, Flash, Pro, Max | Built for Indian languages |

Start with Flash. Move to Pro when the agent needs to reason through harder requests, or to a Sarvam preset when most callers speak an Indian language.
