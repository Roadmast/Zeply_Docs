---
title: "Glossary"
description: "Terms you will see across Sayvy AI and these docs."
---

| Term | Meaning |
|---|---|
| Activity | An entry in a contact's history, such as a call, a message, a note, or a stage change. |
| Agent | The AI that talks to customers. It is a prompt agent, a static bot, or a workflow agent. |
| AI handling | Whether AI is allowed to reply to a contact. Handing off to a human turns it off. |
| Campaign | Outreach to many contacts at once, either a WhatsApp template broadcast or an AI call campaign. |
| Channel | Where a conversation happens: WhatsApp, the web widget, Instagram, or email. |
| Connection | A linked account for a channel, such as your WhatsApp Business number. |
| Contact | A person you've talked to, with their details, tags, custom fields, and history. |
| Custom field | A field you add to contacts for data specific to your business. |
| Deployment | Where an agent is live: the web widget, WhatsApp, or both. |
| Handoff | Passing a conversation from the agent to a teammate, or back again. |
| Inbox thread | All messages between one contact and one of your channel numbers. A thread is open or closed. |
| Knowledge base | Files your agents search for answers. Accepts PDF, DOCX, and TXT. |
| Lead score | A number from 0 to 100 showing how promising a contact is. Agents can change it. |
| Lifecycle stage | Where a contact stands: new, engaged, qualified, customer, or lost. |
| Model preset | The bundle of models an agent runs on, such as Gemini Flash or Sarvam Pro. |
| Quick reply | A saved message your team can insert into a reply. |
| System prompt | The instructions that tell a prompt agent who it is and how to behave. |
| Task | A follow-up item on a contact. It is pending, completed, or cancelled. |
| Template | A WhatsApp message approved by Meta, needed to message a contact outside the 24-hour window. |
| Tool | An action an agent can take mid-conversation, such as booking a slot or calling your API. |
| Webhook | An HTTP request Sayvy AI sends to your server when an event happens. |
| Welcome message | The first thing an agent says when a conversation starts. |
| Workspace | The container for your agents, contacts, inbox, and campaigns. One login can use several. |
