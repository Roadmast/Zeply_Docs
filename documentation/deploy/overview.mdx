---
title: "Deploy overview"
description: "Put an agent live on your website, on WhatsApp, or both."
---

An agent does nothing for customers until you deploy it. Deployment is set on the agent's **Deploy** tab, and an agent can be live in more than one place at once.

| Where | Chat | Voice | Set up on |
|---|---|---|---|
| Website widget | Visitors type to the agent | Visitors call it from the browser | Deploy tab, then the widget settings on **Connections** |
| WhatsApp | The agent replies to messages | The agent answers calls, and places calls in call campaigns | **Connections**, then the Deploy tab |

Instagram and email also connect on the **Connections** page. Conversations from them arrive in the inbox for your team to answer. Agents don't reply on those channels yet.

## Before you deploy

Run through these checks first. They catch most problems before a customer does.

1. Test the agent with **Test Agent**, in both chat and webcall if it takes calls.
2. Turn on **Enable voice** and pick a voice, if you want it to take calls. The widget's voice button and WhatsApp calls both depend on it.
3. Decide whether you want recordings and transcripts. Turn them on in **Advanced Settings** before going live, because calls made earlier aren't recorded after the fact.
4. If the agent books appointments or calls your APIs, make one real booking or API call during a test.
