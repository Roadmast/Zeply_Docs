# Overview

Sayvy AI unifies Web Voice AI agents, WhatsApp Business automation, a native in-built CRM, and long-term conversational memory into a cohesive real-time conversational intelligence platform.

---

## Architecture

```mermaid
graph TD
    subgraph Channels ["Channels"]
        Web[Web Audio / WebRTC]
        WA[WhatsApp Cloud API]
    end

    subgraph Core ["Engine"]
        Voice[Voice AI]
        WhatsApp[WhatsApp Engine]
    end

    subgraph Data ["Data Layer"]
        CRM[Smart CRM]
        Memory[AI Memory]
    end

    Web --> Voice
    WA --> WhatsApp
    WA -.-> Voice
    Voice <--> CRM
    WhatsApp <--> CRM
    Voice <--> Memory
    WhatsApp <--> Memory
    CRM <--> Memory
```
