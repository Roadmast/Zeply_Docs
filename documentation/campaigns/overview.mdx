A campaign sends the same outreach to a group of contacts from one of your WhatsApp Business numbers. Use it for reminders, offers, renewals, or follow-ups, any time you'd otherwise message people one by one.

## Two kinds of campaign

| | Template campaign | Call campaign |
|---|---|---|
| What contacts get | A WhatsApp template message, personalised per contact | A request for permission to call, then a call from your agent |
| Created in | The dashboard, the API, or MCP | The API or MCP |
| Needs | A WhatsApp template | An approved template with a call permission request, and a voice-enabled agent |
| Plan | Not available on Pay as you go | All plans |

Most teams start with template campaigns. See [WhatsApp campaigns](/documentation/campaigns/whatsapp-campaigns) and [Call campaigns](/documentation/campaigns/voice-campaigns).

## Campaign statuses

| Status | Meaning |
|---|---|
| Draft | Saved but not launched |
| Scheduled | Waiting for its launch time |
| Sending | Messages are going out |
| Awaiting responses | Call campaigns only. Permission requests are out, and the agent calls each contact who accepts. |
| Paused | Stopped for now. Resume to carry on where it left off. |
| Completed | Finished |
| Cancelled | Stopped for good |
| Failed | Couldn't run, for example because the template or number is missing |
