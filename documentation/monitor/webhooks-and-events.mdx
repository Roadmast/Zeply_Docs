title: "Webhooks and events"
description: "Send Sayvy AI events to your own server as they happen."
---

Webhooks send an HTTP POST to your server when something happens in your workspace: a message arrives, a call ends, a campaign finishes. Use them to update your own CRM, alert your team in Slack, or start work in another system.

## Add an endpoint

Go to **Developers**, then **Webhooks**, and click **Add Endpoint**. Enter the **Payload URL**, choose the events under **Event Subscriptions**, and save.

The signing secret, starting with `whsec_`, is shown once, straight after you create the endpoint. Copy it then. You need it to [verify requests](/documentation/workflows/outbound-webhooks-dlq).

To change the events, or turn an endpoint off without deleting it, choose **Edit Endpoint** and use **Endpoint Status**.

Your plan sets how many endpoints you can have: none on Pay as you go, 1 on Basic, 3 on Advanced, and 10 on Premium.

## Events

| Area | Events |
|---|---|
| Messages | `message.received`, `message.sent`, `message.failed` |
| Conversations | `conversation.started`, `conversation.closed` |
| Contacts | `lead.created`, `lead.updated` |
| Tickets | `ticket.created`, `ticket.assigned`, `ticket.resolved` |
| AI | `ai.reply.generated`, `ai.tool.executed`, `agent.handoff` |
| Calls | `call.started`, `call.completed` |
| Campaigns | `campaign.started`, `campaign.completed`, `campaign.message.delivered`, `campaign.message.failed` |

`call.started` and `call.completed` cover WhatsApp calls. Browser calls don't send them.

## Payload

Every request has the same envelope. The `data` object depends on the event.

```json
{
  "id": "evt_8f3a2c1d",
  "event": "call.completed",
  "created_at": "2026-11-26T09:41:12Z",
  "workspace_id": "c2a1...",
  "organization_id": "7d4e...",
  "data": { }
}
```

Requests also carry these headers:

| Header | Contains |
|---|---|
| `X-Sayvy-Event` | The event name |
| `X-Sayvy-Delivery` | A unique ID for this delivery |
| `X-Sayvy-Signature-256` | The signature, as `sha256=` followed by the hex digest |
| `User-Agent` | `Sayvy-Webhooks/1.0` |

Respond with any 2xx status within 10 seconds. See [Delivery and security](/documentation/workflows/outbound-webhooks-dlq) for what happens when you don't.
