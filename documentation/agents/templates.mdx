Templates give you a working agent to start from, so you edit instead of writing everything yourself.

## Import an agent template

On the **Agents** page, click **Import Template**. Search by use case, for example front desk, loan, or sales, and import the one closest to what you need. You can give the copy a new name as you import it.

The import copies the template's prompt, model, voice, and tools into a new agent in your workspace. Two things are left out on purpose:

- WhatsApp numbers aren't copied. Assign your own number on the **Deploy** tab.
- Changes you make don't affect the template, and later changes to the template don't reach your copy.

Before you deploy an imported agent, read the prompt from start to finish. Replace the template's business name, hours, and policies with your own, then run a few test calls.

The [Agent Templates](/agent-templates/front-desk-and-wedding-booking-assistant) tab describes the templates and what each one is built for.

## Workflow templates

When you create a workflow agent, the Workflow Builder offers five starting graphs:

| Template | Category | Starts with |
|---|---|---|
| Blank | General | A start step only |
| Lead qualification | Sales | Questions that score and route a new lead |
| Support triage | Support | Working out the problem and routing it |
| Appointment request | Scheduling | Collecting the details needed to book |
| FAQ with handoff | Support | Answering common questions and passing on the rest |

You can also describe the flow you want and use **Build with AI** to draft a graph. It uses AI credits and opens as a draft for you to review.
