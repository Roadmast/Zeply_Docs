## Sayvy MCP Server

Sayvy AI includes a native, production-ready **Model Context Protocol (MCP) server** implementing the official MCP specification (SDK v2). Powered by Streamable HTTP transport at `/mcp`, it exposes 25+ granular tools allowing external LLMs and IDEs to:
- Audit and modify voice agent personas, greetings, and LLM temperature.
- Search and update CRM contacts, adjust lead scores, and append notes.
- Dispatch, pause, and inspect outbound calling campaigns.
- Retrieve full call recordings, latency breakdowns, and dialog transcripts.
- Interact with live knowledge bases and billing summaries.

```bash
# Connect Cursor IDE or Claude Desktop to Sayvy MCP
https://api.sayvy.ai/mcp
```

[Explore the MCP Suite](/developers/mcp/overview) · [MCP Quickstart](/developers/mcp/quickstart) · [Tool List](/developers/mcp/tool-list)

## REST API

Every action available in the Sayvy AI dashboard can be performed via our REST API. Standardized around JSON payloads, Bearer token authentication, and token-bucket rate limiting, developers can integrate Sayvy AI into existing CRMs (Salesforce, HubSpot), ERP systems, and proprietary backends.

* **Base URL:** `https://api.sayvy.ai`
* **Authentication:** `Authorization: Bearer <API_KEY>`

```bash
curl https://api.sayvy.ai/api/agents \
  -H "Authorization: Bearer $SAYVY_API_KEY"
```

[View REST API Reference](/api-reference) · [API Authentication](/api-reference/authentication) · [Rate Limits](/api-reference/rate-limiting)

## Webhooks & Real-Time Events

Stay in sync with customer activity across calls and messaging channels by subscribing your backend endpoints to real-time signed HTTP events:
* `call.completed`: In-depth telemetry including duration, sentiment, user hangup status, and full transcript.
* `message.received`: Real-time incoming chats from WhatsApp, Instagram, Email, or Web Widget.
* `lead.created` / `lead.score_changed`: CRM triggers when leads qualify during automated calls.

All dispatches feature `X-Sayvy-Signature` HMAC-SHA256 headers and automatic retry policies backed by our Dead Letter Queue (DLQ).

## AI-Readable Documentation

Sayvy AI publishes machine-optimized documentation formats designed specifically for consumption by LLMs without scraping HTML:
* **`llms.txt`**: Concise page catalog with summaries for fast agent retrieval.
* **`llms-full.txt`**: Complete documentation concatenated into a single Markdown file for RAG pipelines and prompt contexts.
* **`AGENTS.md`**: Machine-readable specification outlining authentication, base URLs, schemas, and common gotchas.

## Getting Started

<Steps>
  <Step title="Generate an API Key">
    Navigate to **Dashboard → Developers → API Keys** to create a scoped API key for your workspace.
  </Step>
  <Step title="Connect Your IDE via MCP">
    Configure Cursor, Claude Desktop, or Windsurf using our [MCP Quickstart](/developers/mcp/quickstart) to manage your workspace directly from chat.
  </Step>
  <Step title="Install Sayvy Skills">
    Add Sayvy prompt instructions to your project via [Sayvy Skills](/developers/skills/installation) to instruct your AI assistants on proper tool execution.
  </Step>
  <Step title="Configure Webhooks">
    Set up a receiver endpoint and subscribe to `call.completed` and `message.received` events in [Webhooks](/guides/webhooks).
  </Step>
</Steps>
