## API & Protocol Basics

- **REST API Base URL:** `https://api.sayvy.ai`
- **MCP Server Endpoint:** `https://api.sayvy.ai/mcp` (Streamable HTTP transport)
- **Authentication:** Bearer token. Send `Authorization: Bearer <API_KEY>` on every request.

```bash
curl https://api.sayvy.ai/<endpoint> \
  -H "Authorization: Bearer $SAYVY_API_KEY"
```

## Critical Architecture Guidelines

1. **CRM Multi-Tenancy:**
   - Activities and contact operations strictly require `workspace_id`.
   - `organization_id` is reserved for billing and organization membership; do not supply it for contact activities.
2. **Voice Agent Dialog Formatting:**
   - Agents speak through text-to-speech synthesizers. Never emit Markdown syntax (`**bold**`, `#`, bullet lists, backticks) in spoken dialog.
   - Turns must be concise: 1–2 short spoken sentences per turn.
   - Format telephone numbers in E.164 (`+14155552671`).
3. **MCP Tool Calling:**
   - Refer to the official [Sayvy MCP Tool List](/developers/mcp/tool-list).
   - Use validated tools: `list_agents`, `get_agent`, `create_agent`, `list_contacts`, `update_contact_crm`, `create_campaign`, `list_call_logs`.
   - Never invent arbitrary query parameters.
