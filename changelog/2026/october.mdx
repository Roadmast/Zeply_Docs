<Update label="31st October, 2026" description="Billing & Finance">
  ## Online Checkout, Discount Codes & Precise Call Metering

  We have introduced self-serve online checkout, support for promotional discount codes, and precision per-second usage deduction for high-duration calls.

  ### What's New
  * **Self-Serve Plan & Credit Checkout:** Purchase monthly subscriptions or on-demand voice and message credit top-ups directly from your dashboard using domestic and international payment methods.
  * **Dynamic Discount Codes:** Apply fixed or percentage-based promotional coupon codes at checkout with immediate subtotal recalculation.
  * **Precision CDR Metering Fix:** Resolved a credit calculation issue for long-duration calls (>30 minutes). Credits are now deducted on a per-second basis strictly verified against final carrier Call Detail Records (CDRs), eliminating mid-session heartbeat drift.

  <Info>
    Navigate to **Dashboard → Billing** to manage active subscriptions, download tax invoices, or apply voucher codes to your workspace.
  </Info>

<Update label="27th October, 2026" description="Agents & Speech">
  ## Real-Time Live Call Transcription & RAG Retrieval Optimization

  Monitor live calls as they happen and leverage improved Knowledge Base retrieval for complex multi-turn dialogs.

  ### Live Call Transcription
  In-flight audio streams are now captured and transcribed incrementally over WebSocket connections. Supervisors and operators can observe the ongoing conversation in real time with distinct speaker separation (`Agent` vs. `User`).

  ```json
  {
    "event": "transcript.partial",
    "call_id": "c9a1b2c3-d4e5-4f6a-8b9c-0d1e2f3a4b5c",
    "speaker": "user",
    "text": "Can I reschedule my appointment to tomorrow morning?",
    "confidence": 0.98,
    "timestamp_ms": 1420
  }
  ```

  ### Knowledge Base Improvements
  * **Contextual Reranking:** Upgraded search relevance on custom PDFs and uploaded URLs to prevent hallucinations during fast-paced voice interactions.
  * **Fact Grounding:** Voice agents now prioritize authoritative knowledge snippets when answering technical or pricing queries.

  [Call Logs & Live Transcripts](/guides/call-logs) · [Knowledge Base Guide](/documentation/memory/knowledge-base)

<Update label="24th October, 2026" description="Developers & API">
  ## Public REST API Reference & Granular Rate Limiting

  The complete Sayvy AI REST API documentation is now live, accompanied by standard token-bucket rate limiting to guarantee high platform availability.

  ### Developer Features
  * **Interactive API Reference:** Comprehensive endpoint documentation covering Agents, Contacts, Campaigns, Call Logs, Webhooks, and CRM operations with copyable cURL, Python, and JavaScript snippets.
  * **Per-API-Key Rate Limiting:** Outbound calls to public endpoints now return standard rate-limiting headers:
    * `X-RateLimit-Limit`: Maximum requests permitted per minute.
    * `X-RateLimit-Remaining`: Remaining allowance in the current window.
    * `X-RateLimit-Reset`: Unix epoch timestamp when quotas reset.
  * **Scoped Key Management:** Generate and revoke API keys with fine-grained read/write permissions directly in the developer portal.
