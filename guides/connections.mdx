# Manage connected services

Connections let Sayvy exchange data with services such as calendars, messaging providers, and other workspace tools.

## Add a connection

1. Open **Connections** and choose the service.
2. Review the permissions requested before authorizing it.
3. Give the connection a descriptive name if you have more than one account.
4. Run a small test from the workflow or agent that will use it.

## Keep connections healthy

- Remove connections that are no longer used.
- Reauthorize when a provider password, token, or permission changes.
- Use separate credentials for test and production workspaces.
- Give teammates enough access to operate a connection, but not more than they need.

See [Integrations](/documentation/integrations/connected-apps) for implementation details.
