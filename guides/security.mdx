You'll add a second sign-in step with an authenticator app such as Google Authenticator. Ask every admin to do the same.

<Steps>
  <Step title="Open Security">
    Click **Settings**, then **Security**.

    <Visual note="Settings with Security selected" />
  </Step>
  <Step title="Click Setup Google Authenticator">
    A QR code appears.

    <Visual note="QR code shown" />
  </Step>
  <Step title="Scan the code">
    Open your authenticator app and scan it.

    <Visual note="Authenticator app showing the new entry" />
  </Step>
  <Step title="Enter the six-digit code">
    Type the code from the app under **Verify & Enable**, then confirm.

    <Visual note="Verify & Enable with a code typed in" />
  </Step>
</Steps>

<Warning>
Don't put passwords or card numbers in an agent prompt or knowledge base document.
</Warning>
