The **Agents** page lists every agent in your workspace. This is the route from a new agent to one that is live.

<Visual note="Agents page with a few agents listed, New Agent and Import Template visible" />

<Steps>
  <Step title="Create it">
    Click **New Agent**, or **Import Template** to start from a copy. See [Create an agent](/guides/agents/create).
  </Step>
  <Step title="Write the prompt">
    Fill in the **Prompts & Identity** tab. See [Write the prompt and welcome message](/guides/agents/prompts-and-identity).
  </Step>
  <Step title="Pick a voice">
    Use the **AI Model & Voice** tab. See [Choose a model and voice](/guides/agents/model-and-voice).
  </Step>
  <Step title="Add tools">
    Use the **Tools & Integrations** tab. See [Add tools](/guides/agents/tools) and [Set up appointment booking](/guides/agents/booking).
  </Step>
  <Step title="Set recording">
    Use the **Advanced Settings** tab. See [Set recording and follow-ups](/guides/agents/advanced-settings).
  </Step>
  <Step title="Test and deploy">
    Click **Test Agent**, then use the **Deploy** tab. See [Test an agent](/guides/agents/test) and [Deploy an agent](/guides/agents/deploy).
  </Step>
</Steps>
