# Manage message templates

Templates help teams send approved, repeatable messages across supported channels. Keep them clear, current, and aligned with the channel's rules.

## Template checklist

- Use a descriptive name and purpose.
- Keep placeholders obvious and validate them before sending.
- Write for the channel and the customer's context.
- Include a clear next step.
- Review templates whenever policy, pricing, or contact details change.

For API workflows, see [Templates](/api-reference/templates/overview).
