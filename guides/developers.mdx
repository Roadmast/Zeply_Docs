The **Developers** area holds the tools for connecting your own systems to Sayvy AI.

<Visual note="Developers page with API Keys and Webhooks sections" />

<Steps>
  <Step title="Open Developers">
    Click **Developers** in the left sidebar.

    <Visual note="Sidebar with Developers highlighted" />
  </Step>
  <Step title="Create an API key">
    Go to **API Keys** to let your code call Sayvy AI.

    <Visual note="API Keys page" />
  </Step>
  <Step title="Add a webhook">
    Go to **Webhooks** to have Sayvy AI notify your server when things happen.

    <Visual note="Webhooks page" />
  </Step>
</Steps>
