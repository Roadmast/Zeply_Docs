# Campaigns API Reference

The **Campaigns API** empowers you to orchestrate high-volume outbound messaging campaigns across your customer base. You can target specific audiences via tags or direct contact lists, bind approved WhatsApp message templates, execute immediate or scheduled broadcasts, and manage operational lifecycles in real time.

## Quick Example: Creating a Campaign

```bash
curl -X POST "https://api.pingr.ai/api/v1/campaigns" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Q3 Lead Reactivation",
    "whatsapp_phone_number_id": "8f3b0e2a-71d3-4a5f-9e6b-123456789abc",
    "message_template_id": "3a4b5c6d-7e8f-9012-3456-789abcdef012",
    "audience_type": "tags",
    "audience_tags": ["high_intent", "q3_leads"]
  }'
```
