---
title: "Create flow"
sidebarTitle: "Create flow"
api: "POST /api/v1/whatsapp-flows"
description: "Provision a new WhatsApp Flow definition under your organization"
---

Create a new WhatsApp Flow in `DRAFT` status. You can supply an initial Meta Flow JSON screen definition or configure it subsequently via the visual editor or update endpoint.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

The following parameters are accepted in the JSON request body.

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="name" type="string" required>
  Flow name. Example: `Mortgage Lead Qualification`.
</ParamField>

<ParamField body="description" type="string">
  Internal description explaining the flow's objective.
</ParamField>

<ParamField body="category" type="string" default="Lead Generation">
  Flow category (e.g. `Lead Generation`, `Appointment Booking`, `Customer Support`).
</ParamField>

<ParamField body="json_definition" type="object">
  Meta Flow JSON layout definition. If omitted, an empty initial template layout is provisioned.
</ParamField>

<ParamField body="data_api_url" type="string">
  Dynamic data exchange API endpoint URL.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Generated UUID identifier of the flow.
</ResponseField>

<ResponseField name="organization_id" type="string">
  UUID of the organization owning the flow.
</ResponseField>

<ResponseField name="name" type="string">
  Flow title.
</ResponseField>

<ResponseField name="description" type="string">
  Flow description.
</ResponseField>

<ResponseField name="category" type="string">
  Flow category.
</ResponseField>

<ResponseField name="meta_flow_id" type="string">
  Meta Flow ID (assigned upon publishing, initially `null`).
</ResponseField>

<ResponseField name="status" type="string">
  Flow operational status (initially `DRAFT`).
</ResponseField>

<ResponseField name="json_definition" type="object">
  Flow screen layout definition.
</ResponseField>

<ResponseField name="data_api_url" type="string">
  Configured dynamic data exchange endpoint URL.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last modification timestamp.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.pingr.ai/api/v1/whatsapp-flows" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Mortgage Lead Qualification",
    "category": "Lead Generation",
    "description": "Qualify home buyer requirements"
  }'
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/whatsapp-flows"

payload = {
    "name": "Mortgage Lead Qualification",
    "category": "Lead Generation",
    "description": "Qualify home buyer requirements"
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```
