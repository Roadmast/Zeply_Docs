---
title: "Get flow"
sidebarTitle: "Get flow"
api: "GET /api/v1/whatsapp-flows/{flow_id}"
description: "Retrieve comprehensive details, status, and JSON layout definition for a WhatsApp Flow"
---

Retrieve full configuration metadata, Meta Flow ID, category, publishing state, and the entire nested Meta Flow JSON screen definition by flow UUID.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="flow_id" type="string" required>
  Unique UUID identifier of the flow. Example: `1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Flow UUID in Pingr AI.
</ResponseField>

<ResponseField name="organization_id" type="string">
  UUID of the owning organization.
</ResponseField>

<ResponseField name="name" type="string">
  Flow display title.
</ResponseField>

<ResponseField name="description" type="string">
  Detailed flow description.
</ResponseField>

<ResponseField name="category" type="string">
  Flow category (`Lead Generation`, `Appointment Booking`, `Customer Support`, etc.).
</ResponseField>

<ResponseField name="meta_flow_id" type="string">
  Meta Flow ID from WhatsApp Business Platform (if published).
</ResponseField>

<ResponseField name="status" type="string">
  Lifecycle state: `DRAFT`, `PUBLISHED`, or `DEPRECATED`.
</ResponseField>

<ResponseField name="json_definition" type="object">
  Complete Meta Flow JSON screen layout.
</ResponseField>

<ResponseField name="data_api_url" type="string">
  Endpoint URL handling dynamic data exchange events.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last modification timestamp.
</ResponseField>
