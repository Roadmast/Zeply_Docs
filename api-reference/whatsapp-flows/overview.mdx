# WhatsApp Flows API

The **WhatsApp Flows API** enables you to create and orchestrate rich, native, multi-screen conversational form experiences directly within WhatsApp. Unlike simple text or button interactions, WhatsApp Flows provide app-like interactive screens—complete with text inputs, dropdown selects, date pickers, checkboxes, radio buttons, and dynamic data-exchange endpoints.

```
+-------------------------------------------------------------+
|                      WhatsApp Flows Engine                  |
|                                                             |
|   +-----------------------+     +-----------------------+   |
|   | Meta Flow JSON Schema |     | Pre-Built Templates   |   |
|   | (Screens / Components)|     | (Leads / Booking /...) |  |
|   +-----------+-----------+     +-----------+-----------+   |
|               \                             /               |
|                v                           v                |
|              +-------------------------------+              |
|              |     Flow Validation Engine    |              |
|              |   (Syntax / Component Rules)  |              |
|              +---------------+---------------+              |
|                              |                              |
|                              v                              |
|              +-------------------------------+              |
|              |     Meta Business Platform    |              |
|              | (Draft -> Validation -> Publish)|            |
|              +---------------+---------------+              |
|                              |                              |
|                              v                              |
|              +-------------------------------+              |
|              | Dynamic Data Exchange Endpoint|              |
|              |  (Live screen state hydration)|              |
|              +-------------------------------+              |
+-------------------------------------------------------------+
```

## Flow Lifecycle & Statuses

Every WhatsApp Flow progresses through well-defined operational phases:

| Status | Meaning | Operations Permitted |
| :--- | :--- | :--- |
| `DRAFT` | Flow definition is under development | Edit, validate, test execution, publish, delete |
| `PUBLISHED` | Published on Meta Business Platform and live for customer dispatch | Execute data exchange, duplicate, deprecate |
| `DEPRECATED` | Retired flow; cannot be dispatched to new users | Read-only access to historic responses |

---

## Flow Categories

Common business categories supported:
- **Lead Generation**: Capture qualifying contact info, company details, and budget tiers.
- **Appointment Booking**: Select service, choose date and time slot, and confirm contact.
- **Customer Support**: Triage inquiries, gather incident details, and route tickets.
- **Surveys & Feedback**: Collect CSAT ratings, NPS scores, and open-ended feedback.

## Available Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/whatsapp-flows` | List all WhatsApp flows for the organization |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/whatsapp-flows/templates` | Retrieve pre-built flow blueprints and templates |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/whatsapp-flows/validate` | Validate Meta Flow JSON structure and components |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/whatsapp-flows/import` | Import a flow from a raw JSON string |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/whatsapp-flows` | Create a new WhatsApp Flow definition |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/whatsapp-flows/{flow_id}` | Retrieve complete flow metadata and screen JSON |
| <span style={{ color: '#F59E0B', fontWeight: 'bold' }}>PUT</span> | `/api/v1/whatsapp-flows/{flow_id}` | Update flow details, JSON definition, or API endpoint |
| <span style={{ color: '#EF4444', fontWeight: 'bold' }}>DELETE</span> | `/api/v1/whatsapp-flows/{flow_id}` | Permanently delete a WhatsApp Flow |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/whatsapp-flows/{flow_id}/publish` | Publish flow to Meta and mark as live |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/whatsapp-flows/{flow_id}/execute` | Execute or simulate screen data exchange |
