---
title: "Update flow"
sidebarTitle: "Update flow"
api: "PUT /api/v1/whatsapp-flows/{flow_id}"
description: "Modify WhatsApp Flow metadata, status, JSON screen definition, or data exchange URL"
---

Update an existing WhatsApp Flow configuration, modify its screen layouts, or alter its lifecycle state.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="flow_id" type="string" required>
  Unique UUID identifier of the flow to update. Example: `1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="name" type="string">
  Updated flow title.
</ParamField>

<ParamField body="description" type="string">
  Updated internal description.
</ParamField>

<ParamField body="category" type="string">
  Updated category.
</ParamField>

<ParamField body="status" type="string">
  Updated lifecycle state (`DRAFT`, `PUBLISHED`, `DEPRECATED`).
</ParamField>

<ParamField body="meta_flow_id" type="string">
  Associated Meta Flow ID.
</ParamField>

<ParamField body="json_definition" type="object">
  Updated Meta Flow JSON screen definition object.
</ParamField>

<ParamField body="data_api_url" type="string">
  Updated dynamic data exchange webhook URL.
</ParamField>

---

### Response Fields

Returns the updated [WhatsappFlowResponse](/api-reference/whatsapp-flows/get-flow#response-fields) object:

<ResponseField name="id" type="string">Flow UUID.</ResponseField>
<ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
<ResponseField name="name" type="string">Flow title.</ResponseField>
<ResponseField name="status" type="string">Updated status.</ResponseField>
<ResponseField name="json_definition" type="object">Updated screen definition.</ResponseField>
<ResponseField name="updated_at" type="string">Last modification timestamp.</ResponseField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.pingr.ai/api/v1/whatsapp-flows/1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "B2B Lead Flow (Revised)",
    "description": "Updated qualification steps with budget slider"
  }'
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/whatsapp-flows/1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d"

payload = {
    "name": "B2B Lead Flow (Revised)",
    "description": "Updated qualification steps with budget slider"
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.put(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```
