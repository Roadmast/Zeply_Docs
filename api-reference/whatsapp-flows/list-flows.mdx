---
title: "List flows"
sidebarTitle: "List flows"
api: "GET /api/v1/whatsapp-flows"
description: "Retrieve all WhatsApp flows configured for your organization"
---

Returns a list of all WhatsApp Flows registered in your organization, including their categories, current lifecycle statuses (`DRAFT`, `PUBLISHED`, `DEPRECATED`), Meta Flow IDs, and screen JSON configurations.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField query="category" type="string">
  Filter flows by category (e.g. `Lead Generation`, `Appointment Booking`, `Customer Support`).
</ParamField>

---

### Response Fields

Returns an array of [WhatsappFlowResponse](/api-reference/whatsapp-flows/get-flow#response-fields) objects:

<ResponseField name="flows" type="WhatsappFlowResponse[]">
  Array of WhatsApp Flow definitions:
  <Expandable title="Flow object attributes">
    <ResponseField name="id" type="string">Flow UUID.</ResponseField>
    <ResponseField name="organization_id" type="string">Owning organization UUID.</ResponseField>
    <ResponseField name="name" type="string">Flow title.</ResponseField>
    <ResponseField name="description" type="string">Flow description.</ResponseField>
    <ResponseField name="category" type="string">Assigned category.</ResponseField>
    <ResponseField name="meta_flow_id" type="string">Meta Business Platform flow identifier or null.</ResponseField>
    <ResponseField name="status" type="string">Lifecycle status (`DRAFT`, `PUBLISHED`, `DEPRECATED`).</ResponseField>
    <ResponseField name="json_definition" type="object">Full Meta Flow JSON screen definition.</ResponseField>
    <ResponseField name="data_api_url" type="string">Dynamic data exchange endpoint URL or null.</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
    <ResponseField name="updated_at" type="string">Last modification timestamp.</ResponseField>
  </Expandable>
</ResponseField>
