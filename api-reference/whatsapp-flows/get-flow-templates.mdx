---
title: "Get flow templates"
sidebarTitle: "Pre-built templates"
api: "GET /api/v1/whatsapp-flows/templates"
description: "Retrieve curated pre-built WhatsApp Flow templates for quick deployment"
---

Returns the catalog of curated pre-built WhatsApp Flow blueprints provided by Pingr AI. These templates include pre-configured screens, form inputs, validation rules, and JSON definitions for instant cloning.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

Returns an array of `WhatsappFlowTemplateResponse` objects:

<ResponseField name="templates" type="WhatsappFlowTemplateResponse[]">
  Array of template blueprints:
  <Expandable title="Template attributes">
    <ResponseField name="id" type="string">Template identifier slug (e.g. `lead_gen_basic`).</ResponseField>
    <ResponseField name="name" type="string">Template display name.</ResponseField>
    <ResponseField name="description" type="string">Detailed explanation of the flow workflow.</ResponseField>
    <ResponseField name="category" type="string">Template category (`Lead Generation`, `Booking`, etc.).</ResponseField>
    <ResponseField name="icon" type="string">UI icon identifier.</ResponseField>
    <ResponseField name="screen_count" type="number">Number of screens in this flow.</ResponseField>
    <ResponseField name="json_definition" type="object">Ready-to-use Meta Flow JSON definition.</ResponseField>
  </Expandable>
</ResponseField>
