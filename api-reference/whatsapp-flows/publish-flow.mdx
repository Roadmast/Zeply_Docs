---
title: "Publish flow"
sidebarTitle: "Publish flow"
api: "POST /api/v1/whatsapp-flows/{flow_id}/publish"
description: "Publish a WhatsApp Flow to the Meta Business Platform to enable customer dispatch"
---

Publishes a validated WhatsApp Flow to the Meta Business Platform. Once published, the flow transitions from `DRAFT` to `PUBLISHED`, receives a unique `meta_flow_id`, and can be embedded into WhatsApp campaign messages and interactive buttons.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="flow_id" type="string" required>
  Unique UUID identifier of the flow to publish. Example: `1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

Returns the published [WhatsappFlowResponse](/api-reference/whatsapp-flows/get-flow#response-fields) object with status `PUBLISHED`:

<ResponseField name="id" type="string">Flow UUID.</ResponseField>
<ResponseField name="meta_flow_id" type="string">Generated Meta Flow ID.</ResponseField>
<ResponseField name="status" type="string">Updated status: `"PUBLISHED"`.</ResponseField>
<ResponseField name="updated_at" type="string">Publication timestamp.</ResponseField>
