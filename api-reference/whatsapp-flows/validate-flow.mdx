---
title: "Validate flow JSON"
sidebarTitle: "Validate flow"
api: "POST /api/v1/whatsapp-flows/validate"
description: "Verify that a WhatsApp Flow JSON definition satisfies Meta's Flow specification rules"
---

Validate a WhatsApp Flow JSON structure prior to saving or publishing. This endpoint checks for required screen fields, valid layout components, terminal screen configuration, and navigation transitions.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

The raw JSON definition object is passed directly in the request body.

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="version" type="string" required>
  Flow JSON version (e.g. `"3.0"`).
</ParamField>

<ParamField body="screens" type="object[]" required>
  Array of screen definitions comprising layouts, components, and data dependencies.
</ParamField>

---

### Response Fields

<ResponseField name="valid" type="boolean">
  `true` if the definition passes all syntax and schema checks without fatal errors.
</ResponseField>

<ResponseField name="errors" type="string[]">
  Array of fatal validation errors preventing publication.
</ResponseField>

<ResponseField name="warnings" type="string[]">
  Array of non-fatal warnings or optimization recommendations.
</ResponseField>

---

<RequestExample>

```bash cURL
curl -X POST "https://api.pingr.ai/api/v1/whatsapp-flows/validate" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "version": "3.0",
    "screens": [
      {
        "id": "SCREEN_1",
        "title": "Contact Info",
        "terminal": true,
        "data": {},
        "layout": {
          "type": "SingleColumnLayout",
          "children": [
            {
              "type": "TextInput",
              "name": "full_name",
              "label": "Full Name",
              "required": true
            }
          ]
        }
      }
    ]
  }'
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/whatsapp-flows/validate"

payload = {
    "version": "3.0",
    "screens": [
        {
            "id": "SCREEN_1",
            "title": "Contact Info",
            "terminal": True,
            "data": {},
            "layout": {
                "type": "SingleColumnLayout",
                "children": [
                    {
                        "type": "TextInput",
                        "name": "full_name",
                        "label": "Full Name",
                        "required": True
                    }
                ]
            }
        }
    ]
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```

<ResponseExample>

```json 200 OK (Valid)
{
  "valid": true,
  "errors": [],
  "warnings": []
}
```

```json 200 OK (With Errors)
{
  "valid": false,
  "errors": [
    "Screen 'SCREEN_1' must contain at least one interactive component or form footer.",
    "No terminal screen defined in flow."
  ],
  "warnings": [
    "Layout contains unlocalized text string."
  ]
}
```

```json 401 Unauthorized
{
  "detail": "Unauthorized"
}
```
