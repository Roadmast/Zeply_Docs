title: "Import flow JSON"
sidebarTitle: "Import flow"
api: "POST /api/v1/whatsapp-flows/import"
description: "Create a new WhatsApp Flow by importing a raw Meta Flow JSON string"
---

Import and instantiate a new WhatsApp Flow directly from an exported or stringified Meta Flow JSON definition.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

The following parameters are accepted in the JSON request body.

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="name" type="string" required>
  Flow title. Example: `Customer Satisfaction Survey`.
</ParamField>

<ParamField body="category" type="string" default="Lead Generation">
  Flow category (e.g. `Customer Support`, `Lead Generation`, `Surveys`).
</ParamField>

<ParamField body="json_content" type="string" required>
  Raw string containing the complete Meta Flow JSON schema.
</ParamField>

---

### Response Fields

Returns the created [WhatsappFlowResponse](/api-reference/whatsapp-flows/get-flow#response-fields) object with status `DRAFT`.

---

<RequestExample>

```bash cURL
curl -X POST "https://api.pingr.ai/api/v1/whatsapp-flows/import" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Feedback Survey",
    "category": "Customer Support",
    "json_content": "{\"version\":\"3.0\",\"screens\":[{\"id\":\"SCREEN_1\",\"title\":\"Rate Us\",\"terminal\":true,\"data\":{},\"layout\":{\"type\":\"SingleColumnLayout\",\"children\":[]}}]}"
  }'
```

```python Python
import requests
import json

url = "https://api.pingr.ai/api/v1/whatsapp-flows/import"

flow_def = {
    "version": "3.0",
    "screens": [
        {
            "id": "SCREEN_1",
            "title": "Rate Us",
            "terminal": True,
            "data": {},
            "layout": {
                "type": "SingleColumnLayout",
                "children": []
            }
        }
    ]
}

payload = {
    "name": "Feedback Survey",
    "category": "Customer Support",
    "json_content": json.dumps(flow_def)
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```


```java Java
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.pingr.ai/api/v1/whatsapp-flows/import"))

    """))
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```
