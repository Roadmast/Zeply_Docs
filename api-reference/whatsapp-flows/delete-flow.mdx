---
title: "Delete flow"
sidebarTitle: "Delete flow"
api: "DELETE /api/v1/whatsapp-flows/{flow_id}"
description: "Permanently delete a WhatsApp Flow from your organization"
---

Permanently remove a WhatsApp Flow by its UUID identifier. If the flow has already been published to Meta, ensure it is no longer referenced by active campaigns or message templates before deletion.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="flow_id" type="string" required>
  Unique UUID identifier of the flow to delete. Example: `1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

<RequestExample>

```bash cURL
curl -X DELETE "https://api.pingr.ai/api/v1/whatsapp-flows/1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/whatsapp-flows/1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d"

headers = {
    "Authorization": "Bearer <token>"

print(response.status_code)
```
