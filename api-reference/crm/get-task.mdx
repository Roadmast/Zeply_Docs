---
title: "Get CRM task"
sidebarTitle: "Get task"
api: "GET /api/v1/crm/tasks/{task_id}"
description: "Retrieve complete details, status, and associated contact information for a specific CRM task"
---

Retrieve full metadata for a CRM task by its unique identifier, including status (`pending`, `completed`, `cancelled`), due date, assignee, completion timestamp, and linked contact summary.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="task_id" type="string" required>
  Unique UUID identifier of the task. Example: `e4b9d107-1b4e-4f32-8df6-96cbef3e6801`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Task UUID.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Owning organization UUID.
</ResponseField>

<ResponseField name="contact_id" type="string">
  Associated contact UUID.
</ResponseField>

<ResponseField name="title" type="string">
  Task title.
</ResponseField>

<ResponseField name="description" type="string">
  Task description or notes.
</ResponseField>

<ResponseField name="due_at" type="string">
  Due timestamp in ISO 8601 format, or `null`.
</ResponseField>

<ResponseField name="assignee_id" type="string">
  Assigned user UUID or `null`.
</ResponseField>

<ResponseField name="status" type="string">
  Current task status (`pending`, `completed`, `cancelled`).
</ResponseField>

<ResponseField name="created_by_type" type="string">
  Creator actor type (`user`, `ai`, or `system`).
</ResponseField>

<ResponseField name="created_by_id" type="string">
  UUID of user or agent creator, or `null`.
</ResponseField>

<ResponseField name="completed_at" type="string">
  Timestamp when completed, or `null`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last modification timestamp.
</ResponseField>

<ResponseField name="contact" type="object">
  Linked contact summary (`id`, `name`, `phone_number`).
</ResponseField>
