---
title: "Get CRM dashboard metrics"
sidebarTitle: "Dashboard metrics"
api: "GET /api/v1/crm/dashboard"
description: "Retrieve aggregated CRM metrics for contacts, AI/human handling, and tasks"
---

Retrieve executive and operational metrics summarizing your organization's entire CRM state in real time. Returns contacts broken down by lifecycle stage, AI vs human conversation handling counts, and active/overdue task quantities.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="contacts" type="object">
  Contact distribution across pipeline lifecycle stages:
  <Expandable title="Contacts breakdown">
    <ResponseField name="total" type="integer">Total number of contacts in the organization.</ResponseField>
    <ResponseField name="new" type="integer">Contacts in `new` stage.</ResponseField>
    <ResponseField name="engaged" type="integer">Contacts in `engaged` stage.</ResponseField>
    <ResponseField name="qualified" type="integer">Contacts in `qualified` stage.</ResponseField>
    <ResponseField name="customers" type="integer">Contacts marked as `customer` or `customers`.</ResponseField>
    <ResponseField name="lost" type="integer">Contacts marked as `lost`.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="handling" type="object">
  Conversation delegation distribution:
  <Expandable title="Handling breakdown">
    <ResponseField name="ai" type="integer">Contacts currently handled automatically by Voice & Chat AI agents (`ai_handling: true`).</ResponseField>
    <ResponseField name="human" type="integer">Contacts currently routed to human agents (`ai_handling: false`).</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tasks" type="object">
  Operational task statistics:
  <Expandable title="Tasks breakdown">
    <ResponseField name="pending" type="integer">Total active tasks in `pending` status.</ResponseField>
    <ResponseField name="overdue" type="integer">Pending tasks whose `due_at` timestamp is earlier than current time.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.sayvy.ai/api/v1/crm/dashboard" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/crm/dashboard"

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.get(url, headers=headers)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.sayvy.ai/api/v1/crm/dashboard", {
  method: "GET",
  headers: {
    "Authorization": "Bearer <token>"
  }
});

const data = await response.json();
console.log(data);
```

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.sayvy.ai/api/v1/crm/dashboard"))
    .header("Authorization", "Bearer <token>")
    .GET()
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```
