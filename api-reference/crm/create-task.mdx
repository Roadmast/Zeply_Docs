---
title: "Create CRM task"
sidebarTitle: "Create task"
api: "POST /api/v1/crm/tasks"
description: "Create a new CRM task linked to a contact and emit a task_created activity event"
---

Create a new follow-up task or reminder linked to an existing contact. Creating a task automatically emits a `task_created` audit event on the contact's [activity timeline](/api-reference/contacts/get-activities).

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="contact_id" type="string" required>
  UUID of the existing contact this task is associated with. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField body="title" type="string" required>
  Task title or summary action item (maximum 255 characters). Example: `Review customer custom pricing request`.
</ParamField>

<ParamField body="description" type="string">
  Detailed task description, conversation context, or instructions.
</ParamField>

<ParamField body="due_at" type="string">
  Target completion deadline in ISO 8601 format (e.g. `2026-10-15T15:00:00Z`).
</ParamField>

<ParamField body="assignee_id" type="string">
  UUID of the team member assigned to execute the task.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Generated UUID identifier of the created task.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Organization UUID.
</ResponseField>

<ResponseField name="contact_id" type="string">
  Associated contact UUID.
</ResponseField>

<ResponseField name="title" type="string">
  Task title.
</ResponseField>

<ResponseField name="description" type="string">
  Detailed description or `null`.
</ResponseField>

<ResponseField name="due_at" type="string">
  Due timestamp in ISO 8601 format, or `null`.
</ResponseField>

<ResponseField name="assignee_id" type="string">
  Assigned user UUID or `null`.
</ResponseField>

<ResponseField name="status" type="string">
  Initialized state: `pending`.
</ResponseField>

<ResponseField name="created_by_type" type="string">
  Actor type that initiated the task (`user`).
</ResponseField>

<ResponseField name="created_by_id" type="string">
  UUID of the creating user.
</ResponseField>

<ResponseField name="completed_at" type="string">
  Timestamp of completion (`null` upon creation).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 modification timestamp.
</ResponseField>

<ResponseField name="contact" type="object">
  Linked contact summary (`id`, `name`, `phone_number`).
</ResponseField>

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/crm/tasks"

payload = {
    "contact_id": "7b8f9e2a-4c1d-48ef-9123-bcde456789ab",
    "title": "Send updated contract agreement",
    "description": "Include annual billing terms and SLA addendum.",
    "due_at": "2026-10-15T17:00:00Z",
    "assignee_id": "a1b2c3d4-e5f6-4a5b-8c9d-0e1f2a3b4c5d"
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String jsonPayload = """
{
  "contact_id": "7b8f9e2a-4c1d-48ef-9123-bcde456789ab",
  "title": "Send updated contract agreement",
  "due_at": "2026-10-15T17:00:00Z"
}
""";

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.sayvy.ai/api/v1/crm/tasks"))
    .header("Authorization", "Bearer <token>")
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(jsonPayload))
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```
