---
title: "Delete CRM task"
sidebarTitle: "Delete task"
api: "DELETE /api/v1/crm/tasks/{task_id}"
description: "Permanently delete a task within an organization"
---

Permanently remove a CRM follow-up task by its unique identifier. This action enforces tenant boundary checks; attempting to delete a task belonging to another organization returns a `404 Not Found` response.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="task_id" type="string" required>
  Unique UUID identifier of the task to delete. Example: `e4b9d107-1b4e-4f32-8df6-96cbef3e6801`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="message" type="string">
  Confirmation response: `"Task deleted successfully"`.
</ResponseField>

---

<RequestExample>

```bash cURL
curl -X DELETE "https://api.sayvy.ai/api/v1/crm/tasks/e4b9d107-1b4e-4f32-8df6-96cbef3e6801" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/crm/tasks/e4b9d107-1b4e-4f32-8df6-96cbef3e6801"

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.delete(url, headers=headers)
print(response.status_code)
print(response.json())
```

```java Java
import java.net.URI;

import java.net.http.HttpRequest;
```
