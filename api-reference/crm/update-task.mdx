---
title: "Update CRM task"
sidebarTitle: "Update task"
api: "PATCH /api/v1/crm/tasks/{task_id}"
description: "Update task details, reassign team members, or transition task status"
---

Update attributes of an existing CRM task. You can modify task titles, due dates, instructions, reassign the task to a different team member, or change its lifecycle status (`pending`, `completed`, `cancelled`).

<Tip>
When transitioning a task status to `completed`, the system automatically logs a `task_completed` event to the linked contact's [activity timeline](/api-reference/contacts/get-activities) and stamps `completed_at`.
</Tip>

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="task_id" type="string" required>
  Unique UUID identifier of the task. Example: `e4b9d107-1b4e-4f32-8df6-96cbef3e6801`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="status" type="string">
  New operational status for the task: `pending`, `completed`, or `cancelled`.
</ParamField>

<ParamField body="title" type="string">
  Updated title or subject of the task (maximum 255 characters).
</ParamField>

<ParamField body="description" type="string">
  Updated task description or notes.
</ParamField>

<ParamField body="due_at" type="string">
  Updated due datetime in ISO 8601 format (e.g. `2026-10-20T17:00:00Z`).
</ParamField>

<ParamField body="assignee_id" type="string">
  UUID of the team member to reassign this task to.
</ParamField>

---

### Response Fields

Returns the updated [TaskResponse](/api-reference/crm/get-task#response-fields) object:

<ResponseField name="id" type="string">Task UUID.</ResponseField>
<ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
<ResponseField name="contact_id" type="string">Associated contact UUID.</ResponseField>
<ResponseField name="title" type="string">Task title.</ResponseField>
<ResponseField name="description" type="string">Task description or notes.</ResponseField>
<ResponseField name="due_at" type="string">Due timestamp in ISO 8601 format, or `null`.</ResponseField>
<ResponseField name="assignee_id" type="string">Assigned user UUID or `null`.</ResponseField>
<ResponseField name="status" type="string">Current status (`pending`, `completed`, `cancelled`).</ResponseField>
<ResponseField name="created_by_type" type="string">Creator type (`user`, `ai`, or `system`).</ResponseField>
<ResponseField name="created_by_id" type="string">Creator UUID or `null`.</ResponseField>
<ResponseField name="completed_at" type="string">ISO 8601 completion timestamp if completed, or `null`.</ResponseField>
<ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
<ResponseField name="updated_at" type="string">Modification timestamp.</ResponseField>
<ResponseField name="contact" type="object">Contact summary (`id`, `name`, `phone_number`).</ResponseField>

<RequestExample>

```bash cURL
curl -X PATCH "https://api.sayvy.ai/api/v1/crm/tasks/e4b9d107-1b4e-4f32-8df6-96cbef3e6801" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "completed",
    "description": "Proposal sent and reviewed by client CFO."
  }'
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/crm/tasks/e4b9d107-1b4e-4f32-8df6-96cbef3e6801"

payload = {
    "status": "completed",
    "description": "Proposal sent and reviewed by client CFO."
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.patch(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String jsonPayload = """
{
  "status": "completed"
}
""";

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.sayvy.ai/api/v1/crm/tasks/e4b9d107-1b4e-4f32-8df6-96cbef3e6801"))
    .header("Authorization", "Bearer <token>")
    .header("Content-Type", "application/json")
    .method("PATCH", HttpRequest.BodyPublishers.ofString(jsonPayload))
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```
