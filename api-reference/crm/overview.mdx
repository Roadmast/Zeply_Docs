# CRM API

The **CRM API** enables you to inspect organization-level pipeline velocity, retrieve real-time operational dashboard metrics, and orchestrate customer follow-up tasks linked to contacts and team members.

```
+---------------------------------------------------------------------------------+
|                               Sayvy AI CRM System                               |
|                                                                                 |
|  +-------------------------+         +---------------------------------------+  |
|  |   Executive Dashboard   |         |           Task Orchestration          |  |
|  |  * Pipeline Stages      |         |  * Follow-up Actions & Reminders      |  |
|  |  * AI vs Human Ratio    |         |  * Contact Linkage & Team Assignment  |  |
|  |  * Pending & Overdue    |         |  * State Transitions (Done/Cancelled) |  |
|  +------------+------------+         +-------------------+-------------------+  |
|               |                                          |                      |
|               v                                          v                      |
|  +---------------------------------------------------------------------------+  |
|  |                         Contact Activity Timeline                         |  |
|  |          (task_created, task_completed, stage_changed, notes)            |  |
|  +---------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------+
```

## Task Model Schema

Tasks in Sayvy AI represent follow-up obligations linked to a specific customer contact:

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | Unique identifier of the task. |
| `organization_id` | `UUID` | Owning organization identifier. |
| `contact_id` | `UUID` | Associated contact UUID. |
| `title` | `string` | Task title or subject (1–255 characters). |
| `description` | `string` | Detailed notes or instructions for the task, or `null`. |
| `due_at` | `string` | ISO 8601 datetime when the task is due, or `null`. |
| `assignee_id` | `UUID` | User UUID assigned to execute this task, or `null`. |
| `status` | `string` | Task state: `pending`, `completed`, or `cancelled`. |
| `created_by_type` | `string` | Creator actor type: `user`, `ai`, or `system`. |
| `created_by_id` | `UUID` | Identifier of the user or agent creator, or `null`. |
| `completed_at` | `string` | ISO 8601 timestamp when status changed to `completed`, or `null`. |
| `created_at` | `string` | ISO 8601 creation timestamp. |
| `updated_at` | `string` | ISO 8601 modification timestamp. |
| `contact` | `object` | Lightweight summary of the associated contact (`id`, `name`, `phone_number`). |

## Available Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/crm/dashboard` | Retrieve aggregated pipeline, handling, and task metrics |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/crm/tasks` | List and filter tasks by status, contact, assignee, or due dates |
| <span style={{ color: '#3B82F6', fontWeight: 'bold' }}>POST</span> | `/api/v1/crm/tasks` | Create a new task linked to a contact |
| <span style={{ color: '#10B981', fontWeight: 'bold' }}>GET</span> | `/api/v1/crm/tasks/{task_id}` | Retrieve a single task by ID |
| <span style={{ color: '#8B5CF6', fontWeight: 'bold' }}>PATCH</span> | `/api/v1/crm/tasks/{task_id}` | Update task details, reassign, or transition status |
| <span style={{ color: '#EF4444', fontWeight: 'bold' }}>DELETE</span> | `/api/v1/crm/tasks/{task_id}` | Permanently delete a task |
