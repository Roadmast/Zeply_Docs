---
title: "Partially update contact CRM"
sidebarTitle: "Update CRM fields"
api: "PATCH /api/v1/contacts/{contact_id}"
description: "Partially update contact CRM attributes with automatic activity logging and transactional guarantees"
---

Partially update CRM pipeline attributes on a contact record, including lifecycle stage transitions, lead scoring adjustments, owner reassignments, and AI handling delegation.

Whenever lifecycle stages, scores, or AI handling settings change, the system automatically appends an audit event to the contact's [activity timeline](/api-reference/contacts/get-activities) (such as `stage_changed`, `lead_score_changed`, `handoff_to_human`, or `handoff_to_ai`).

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="contact_id" type="string" required>
  Unique UUID identifier of the contact. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="lifecycle_stage" type="string">
  Target CRM lifecycle stage: `new`, `engaged`, `qualified`, `customer`, or `lost`.
</ParamField>

<ParamField body="lead_score" type="integer">
  Numerical lead score between `0` and `100`.
</ParamField>

<ParamField body="owner_id" type="string">
  UUID of the assigned team member, or `null` to unassign.
</ParamField>

<ParamField body="ai_handling" type="boolean">
  Toggle between automated AI engine handling (`true`) or human agent takeover (`false`).
</ParamField>

<ParamField body="name" type="string">
  Updated full name of the contact.
</ParamField>

<ParamField body="tags" type="string[]">
  Updated array of classification tags.
</ParamField>

<ParamField body="notes" type="string">
  Updated internal notes.
</ParamField>

<ParamField body="custom_fields" type="object">
  Updated custom metadata attributes dictionary.
</ParamField>

---

### Response Fields

Returns the updated [ContactResponse](/api-reference/contacts/get-contact#response-fields) object:

<ResponseField name="id" type="string">Contact UUID.</ResponseField>
<ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
<ResponseField name="phone_number" type="string">Telephone number.</ResponseField>
<ResponseField name="name" type="string">Updated contact name.</ResponseField>
<ResponseField name="tags" type="string[]">Updated classification tags.</ResponseField>
<ResponseField name="notes" type="string">Updated notes text.</ResponseField>
<ResponseField name="custom_fields" type="object">Updated metadata object.</ResponseField>
<ResponseField name="lifecycle_stage" type="string">Updated lifecycle stage (`new`, `engaged`, `qualified`, `customer`, `lost`).</ResponseField>
<ResponseField name="lead_score" type="integer">Updated lead qualification score (0–100).</ResponseField>
<ResponseField name="owner_id" type="string">Assigned owner UUID or `null`.</ResponseField>
<ResponseField name="ai_handling" type="boolean">Current AI handling status.</ResponseField>
<ResponseField name="last_activity_at" type="string">Timestamp of the newly registered activity.</ResponseField>
<ResponseField name="source" type="string">Contact origin.</ResponseField>
<ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
<ResponseField name="updated_at" type="string">Modification timestamp.</ResponseField>

```bash cURL
curl -X PATCH "https://api.sayvy.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "lifecycle_stage": "qualified",
    "lead_score": 90,
    "ai_handling": false,

  }'
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab"

payload = {
    "lifecycle_stage": "qualified",
    "lead_score": 90,
    "ai_handling": False,
    "owner_id": "a1b2c3d4-e5f6-4a5b-8c9d-0e1f2a3b4c5d"
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.patch(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```
