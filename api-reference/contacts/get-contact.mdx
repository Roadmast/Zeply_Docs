---
title: "Get contact"
sidebarTitle: "Get contact"
api: "GET /api/v1/contacts/{contact_id}"
description: "Retrieve complete profile, segmentation, and CRM details for a specific contact"
---

Retrieve comprehensive profile information, segmentation tags, custom metadata, and current CRM attributes (lifecycle stage, lead score, assigned owner, AI handling status) for an individual contact by UUID.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="contact_id" type="string" required>
  Unique UUID identifier of the contact. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Unique UUID identifier of the contact.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Owning organization UUID.
</ResponseField>

<ResponseField name="phone_number" type="string">
  Customer telephone number.
</ResponseField>

<ResponseField name="name" type="string">
  Full name of the contact.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Array of assigned classification tags.
</ResponseField>

<ResponseField name="notes" type="string">
  Internal context or notes.
</ResponseField>

<ResponseField name="custom_fields" type="object">
  Key-value dictionary containing arbitrary custom metadata.
</ResponseField>

<ResponseField name="lifecycle_stage" type="string">
  Current CRM lifecycle stage: `new`, `engaged`, `qualified`, `customer`, or `lost`.
</ResponseField>

<ResponseField name="lead_score" type="integer">
  Numerical lead qualification score between `0` and `100`.
</ResponseField>

<ResponseField name="owner_id" type="string">
  UUID of the assigned team member, or `null`.
</ResponseField>

<ResponseField name="ai_handling" type="boolean">
  Whether automated AI voice/chat systems handle interactions (`true`) or human agents (`false`).
</ResponseField>

<ResponseField name="last_activity_at" type="string">
  ISO 8601 timestamp of the most recent interaction or timeline activity event.
</ResponseField>

<ResponseField name="source" type="string">
  Origin channel of the contact (e.g. `manual`, `bulk_upload`, `inbound_call`).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 modification timestamp.
</ResponseField>
