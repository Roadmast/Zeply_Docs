---
title: "Get contact activities"
sidebarTitle: "List activities"
api: "GET /api/v1/contacts/{contact_id}/activities"
description: "Retrieve chronological activity timeline for a contact"
---

Retrieve a chronological, paginated activity timeline for a contact (newest first). The timeline tracks all interactions, system events, manual agent notes, campaign messages, lifecycle stage changes, and AI/human handoffs.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="contact_id" type="string" required>
  Unique UUID identifier of the contact. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of activities to return (minimum 1, maximum 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of activities to skip for pagination.
</ParamField>

<ParamField query="activity_types" type="string[]">
  Optional filter by one or more activity types (e.g. `note_added`, `stage_changed`, `lead_score_changed`, `handoff_to_human`, `handoff_to_ai`, `task_created`, `task_completed`, `message_inbound`, `message_outbound`).
</ParamField>

---

### Response Fields

<ResponseField name="activities" type="ActivityResponse[]">
  List of chronological activity records:
  <Expandable title="Activity record fields">
    <ResponseField name="id" type="string">Unique UUID identifier of the activity.</ResponseField>
    <ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
    <ResponseField name="contact_id" type="string">Associated contact UUID.</ResponseField>
    <ResponseField name="type" type="string">Activity type event string (e.g. `contact_created`, `note_added`, `stage_changed`, `lead_score_changed`, `handoff_to_human`, `handoff_to_ai`, `task_created`, `task_completed`).</ResponseField>
    <ResponseField name="actor_type" type="string">Initiator type: `user`, `ai`, or `system`.</ResponseField>
    <ResponseField name="actor_id" type="string">UUID of the user or agent actor, or `null`.</ResponseField>
    <ResponseField name="payload" type="object">Event metadata dictionary containing details (such as previous stage, new stage, note text, task ID, etc.).</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total count of activities matching filters.
</ResponseField>

<ResponseField name="limit" type="integer">
  Limit requested.
</ResponseField>

<ResponseField name="offset" type="integer">
  Pagination offset applied.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Flag indicating if more activities exist beyond this page.
</ResponseField>
