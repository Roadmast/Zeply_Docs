---
title: "List contacts"
sidebarTitle: "List contacts"
api: "GET /api/v1/contacts"
description: "Retrieve contacts associated with your organization with CRM filters and pagination"
---

Returns a paginated list of contacts for your organization. Supports advanced CRM query filtering including search terms, lifecycle stages, assigned owners, AI handling delegation, lead scores, classification tags, and activity recency.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Query Parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1).
</ParamField>

<ParamField query="page_size" type="integer" default="50">
  Number of contacts per page (minimum 1, maximum 100).
</ParamField>

<ParamField query="limit" type="integer">
  Alternative alias for `page_size` (minimum 1, maximum 100).
</ParamField>

<ParamField query="search" type="string">
  Search term matching contact names or telephone numbers.
</ParamField>

<ParamField query="lifecycle_stage" type="string">
  Filter by CRM lifecycle stage (`new`, `engaged`, `qualified`, `customer`, `lost`).
</ParamField>

<ParamField query="owner_id" type="string">
  Filter by assigned owner user UUID.
</ParamField>

<ParamField query="ai_handling" type="boolean">
  Filter by AI handling state (`true` for AI automated, `false` for human agent).
</ParamField>

<ParamField query="min_lead_score" type="integer">
  Filter contacts with lead score greater than or equal to this integer (0–100).
</ParamField>

<ParamField query="max_lead_score" type="integer">
  Filter contacts with lead score less than or equal to this integer (0–100).
</ParamField>

<ParamField query="tag" type="string">
  Filter contacts having a specific classification tag (e.g. `vip`).
</ParamField>

<ParamField query="last_activity_before" type="string">
  Filter contacts active before this ISO 8601 datetime (e.g. `2026-10-01T00:00:00Z`).
</ParamField>

---

### Response Fields

<ResponseField name="contacts" type="ContactResponse[]">
  Array of contact objects:
  <Expandable title="Contact item attributes">
    <ResponseField name="id" type="string">Contact UUID.</ResponseField>
    <ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
    <ResponseField name="phone_number" type="string">Destination telephone number.</ResponseField>
    <ResponseField name="name" type="string">Contact display name.</ResponseField>
    <ResponseField name="tags" type="string[]">Assigned classification tags.</ResponseField>
    <ResponseField name="notes" type="string">Internal notes text.</ResponseField>
    <ResponseField name="custom_fields" type="object">Arbitrary metadata key-value dictionary.</ResponseField>
    <ResponseField name="lifecycle_stage" type="string">Lifecycle pipeline stage (`new`, `engaged`, `qualified`, `customer`, `lost`).</ResponseField>
    <ResponseField name="lead_score" type="integer">Lead score integer (0–100).</ResponseField>
    <ResponseField name="owner_id" type="string">Assigned team member UUID or `null`.</ResponseField>
    <ResponseField name="ai_handling" type="boolean">Whether AI handles interactions (`true`) or human (`false`).</ResponseField>
    <ResponseField name="last_activity_at" type="string">ISO 8601 timestamp of last interaction.</ResponseField>
    <ResponseField name="source" type="string">Origin source (`manual`, `bulk_upload`, `inbound_call`).</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
    <ResponseField name="updated_at" type="string">ISO 8601 modification timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total count of contacts matching query filters.
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number.
</ResponseField>

<ResponseField name="page_size" type="integer">
  Number of items per page.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Flag indicating whether additional pages of results are available.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.sayvy.ai/api/v1/contacts?lifecycle_stage=qualified&ai_handling=true&page=1&page_size=20" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/contacts"

params = {
    "lifecycle_stage": "qualified",
    "ai_handling": "true",
    "page": 1,
    "page_size": 20
}

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.get(url, headers=headers, params=params)
print(response.status_code)
print(response.json())
```


