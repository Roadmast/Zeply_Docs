---
title: "Create contact activity"
sidebarTitle: "Add activity or note"
api: "POST /api/v1/contacts/{contact_id}/activities"
description: "Log a manual note or activity event against a contact record"
---

Log an internal note, manual action, or custom activity event against a contact. Adding a `note_added` activity automatically synchronizes with the contact's CRM interaction history and updates the contact's `last_activity_at` timestamp.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="contact_id" type="string" required>
  Unique UUID identifier of the contact. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="type" type="string" default="note_added">
  Activity type identifier matching standard events (e.g. `note_added`, `meeting_scheduled`, `call_logged`).
</ParamField>

<ParamField body="note" type="string">
  Direct textual note content (e.g. `"Customer requested custom SLA terms."`).
</ParamField>

<ParamField body="payload" type="object">
  Optional JSON dictionary containing additional event metadata and attributes.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Generated UUID identifier of the activity.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Organization UUID.
</ResponseField>

<ResponseField name="contact_id" type="string">
  Associated contact UUID.
</ResponseField>

<ResponseField name="type" type="string">
  Activity type event recorded.
</ResponseField>

<ResponseField name="actor_type" type="string">
  Actor attribution type (typically `user`).
</ResponseField>

<ResponseField name="actor_id" type="string">
  UUID of the authenticated user who created the note/activity.
</ResponseField>

<ResponseField name="payload" type="object">
  Stored event metadata dictionary.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.sayvy.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab/activities" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "note_added",
    "note": "Spoke on phone regarding enterprise migration timeline.",
    "payload": {
      "channel": "phone",
      "call_duration_mins": 15
    }
  }'
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab/activities"

payload = {
    "type": "note_added",
    "note": "Spoke on phone regarding enterprise migration timeline.",
    "payload": {
        "channel": "phone",
        "call_duration_mins": 15
    }
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String jsonPayload = """
{
  "type": "note_added",
  "note": "Spoke on phone regarding enterprise migration timeline."
}
""";

    .uri(URI.create("https://api.sayvy.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab/activities"))

    .header("Content-Type", "application/json")
```
