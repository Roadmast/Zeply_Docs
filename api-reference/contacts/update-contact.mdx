---
title: "Update contact"
sidebarTitle: "Update contact"
api: "PUT /api/v1/contacts/{contact_id}"
description: "Modify an existing contact's details, tags, or custom metadata"
---

Update profile fields, assign or replace segmentation tags, and edit custom key-value metadata on an existing contact record.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="contact_id" type="string" required>
  Unique UUID identifier of the contact to update. Example: `7b8f9e2a-4c1d-48ef-9123-bcde456789ab`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField body="name" type="string">
  Updated full name of the contact.
</ParamField>

<ParamField body="phone_number" type="string">
  Updated destination telephone number.
</ParamField>

<ParamField body="tags" type="string[]">
  Updated array of segmentation tags (e.g. `["vip", "churn_risk"]`).
</ParamField>

<ParamField body="notes" type="string">
  Updated internal notes.
</ParamField>

<ParamField body="custom_fields" type="object">
  Updated custom metadata attributes dictionary.
</ParamField>

---

### Response Fields

Returns the updated [ContactResponse](/api-reference/contacts/create-contact#response-fields) object:

<ResponseField name="id" type="string">Contact UUID.</ResponseField>
<ResponseField name="organization_id" type="string">Organization UUID.</ResponseField>
<ResponseField name="phone_number" type="string">Updated telephone number.</ResponseField>
<ResponseField name="name" type="string">Updated full name.</ResponseField>
<ResponseField name="tags" type="string[]">Updated segmentation tags.</ResponseField>
<ResponseField name="notes" type="string">Updated internal notes.</ResponseField>
<ResponseField name="custom_fields" type="object">Updated metadata object.</ResponseField>
<ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
<ResponseField name="updated_at" type="string">Modification timestamp.</ResponseField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.pingr.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe-Smith",
    "tags": ["vip", "promoter"],
    "notes": "Upgraded to Enterprise tier"
  }'
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/contacts/7b8f9e2a-4c1d-48ef-9123-bcde456789ab"

payload = {
    "name": "Jane Doe-Smith",
    "tags": ["vip", "promoter"],
    "notes": "Upgraded to Enterprise tier"
}

headers = {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
}

response = requests.put(url, json=payload, headers=headers)
print(response.status_code)
print(response.json())
```
