# Pingr AI REST API

All API endpoints are served from `https://api.pingr.ai` (or `http://localhost:8000` during local development).

## Base URLs

- **Production**: `https://api.pingr.ai/api/v1`
- **Development**: `http://localhost:8000/api/v1`
