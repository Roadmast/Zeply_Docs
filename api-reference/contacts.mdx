# Contacts API Reference

The **Contacts API** provides comprehensive programmatic control over your organization's customer and lead directories. Define phone numbers, assign classification tags for audience targeting, store extensible JSON metadata, manage CRM lifecycle stages and lead scoring, track chronological activity timelines, and import bulk contact lists via spreadsheets.

## Quick Example: Creating a Contact

```bash
curl -X POST "https://api.sayvy.ai/api/v1/contacts" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "+14155550199",
    "name": "Jane Doe",
    "tags": ["vip", "enterprise"],
    "notes": "Interested in enterprise pricing"
  }'
```
