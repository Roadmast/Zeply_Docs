# WhatsApp Flows API Reference

The **WhatsApp Flows API** allows you to programmatically design, validate, manage, publish, and execute native interactive flows on the WhatsApp Business Platform. WhatsApp Flows empower businesses to deliver app-like rich interactions—such as lead generation questionnaires, appointment scheduling, event RSVPs, and dynamic order customizers—directly within WhatsApp chats.

## Quick Example: Creating a Flow

```bash
curl -X POST "https://api.pingr.ai/api/v1/whatsapp-flows" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Quick Lead Form",
    "category": "Lead Generation",
    "json_definition": {
      "version": "3.0",
      "screens": [
        {
          "id": "LEAD_SCREEN",
          "title": "Contact Details",
          "layout": { "type": "SingleColumnLayout", "children": [] }
        }
      ]
    }
  }'
```
