# Templates API Reference

The **Templates API** provides full programmatic control over WhatsApp Business message templates. Create custom multi-component templates (Header, Body, Footer, Buttons), synchronize review statuses from Meta Graph API, and browse Meta's pre-approved global template catalog for instant provisioning.

## Quick Example: Submitting a Template

```bash
curl -X POST "https://api.pingr.ai/api/v1/templates" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "channel_id": "8f3b0e2a-71d3-4a5f-9e6b-123456789abc",
    "name": "order_confirmation_v1",
    "language": "en_US",
    "category": "UTILITY",
    "components": [
      {
        "type": "BODY",
        "text": "Hi {{1}}, your order #{{2}} has been confirmed!"
      }
    ]
  }'
```
