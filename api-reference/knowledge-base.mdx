# Knowledge Base API Reference

The **Knowledge Base API** enables you to programmatically upload and manage internal corporate documents (`PDF`, `DOCX`, `TXT`). Source files are securely stored in object storage, while extracted text chunks and vector embeddings are stored in Pingr AI's vector database to empower Voice AI agents with contextual retrieval during customer calls.

## Quick Example: Uploading a Document

```bash
curl -X POST "https://api.pingr.ai/api/v1/knowledge-base/upload" \
  -H "Authorization: Bearer <your-api-key>" \
  -F "file=@/path/to/faq.pdf"
```
