---
title: "Delete agent"
sidebarTitle: "Delete agent"
api: "DELETE /api/v1/agents/{agent_id}"
description: "Permanently remove an existing Voice AI agent"
---

Permanently deletes the specified agent and detaches all associated telephony phone number bindings. Active calls will be hung up before deletion is completed.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

---

### Input parameters

<ParamField path="agent_id" type="string" required>
  Unique identifier of the agent to delete. Example: `agent_12345`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

<RequestExample>

```python Python
import requests

url = "https://api.pingr.ai/api/v1/agents/agent_12345"

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.delete(url, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.pingr.ai/api/v1/agents/agent_12345", {
  method: "DELETE",
  headers: {
    "Authorization": "Bearer <token>"
  }
});

const data = await response.json();
console.log(data);
```

```java Java
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.pingr.ai/api/v1/agents/agent_12345"))
    .header("Authorization", "Bearer <token>")
    .DELETE()
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

```bash cURL
curl -X DELETE "https://api.pingr.ai/api/v1/agents/agent_12345" \
  -H "Authorization: Bearer <token>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "status": "success",
  "message": "Agent agent_12345 deleted successfully"
```

```json 404 Not Found

  "message": "Agent not found"

```
