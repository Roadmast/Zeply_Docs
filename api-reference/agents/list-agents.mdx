---
title: "List agents"
sidebarTitle: "List agents"
api: "GET /api/v1/agents"
description: "Retrieve all Voice AI agents belonging to your organization"
---

Returns a paginated list of all voice agents provisioned within the authenticated organization, including active prompts, voice configurations, and telephony bindings.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="agents" type="AgentResponse[]">
  Array of agent summary objects:
  <Expandable title="Agent item attributes">
    <ResponseField name="id" type="string">Agent UUID.</ResponseField>
    <ResponseField name="name" type="string">Agent display name.</ResponseField>
    <ResponseField name="agent_type" type="string">`prompt` or `static`.</ResponseField>
    <ResponseField name="is_active" type="string">`active` or `inactive`.</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
  </Expandable>
</ResponseField>
