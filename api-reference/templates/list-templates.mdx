---
title: "List templates"
sidebarTitle: "List templates"
api: "GET /api/v1/templates"
description: "Retrieve a paginated list of WhatsApp message templates for your organization"
---

Returns paginated message templates configured within your organization, including their current review status (`PENDING`, `APPROVED`, `REJECTED`), languages, categories, and component structures.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField query="limit" type="number" default="100">
  Maximum number of templates to retrieve per page (min `1`, max `100`).
</ParamField>

<ParamField query="page" type="number" default="1">
  Page number (starts at `1`).
</ParamField>

---

### Response Fields

<ResponseField name="has_more" type="boolean">
  Whether additional pages exist.
</ResponseField>

<ResponseField name="total" type="number">
  Total number of templates across all pages.
</ResponseField>

<ResponseField name="page" type="number">
  Current page number.
</ResponseField>

<ResponseField name="limit" type="number">
  Items per page limit applied.
</ResponseField>

<ResponseField name="items" type="MessageTemplateResponse[]">
  Array of message templates:
  <Expandable title="Template object attributes">
    <ResponseField name="id" type="string">Template UUID.</ResponseField>
    <ResponseField name="channel_id" type="string">WhatsApp phone number channel UUID.</ResponseField>
    <ResponseField name="waba_id" type="string">Meta WABA identifier.</ResponseField>
    <ResponseField name="meta_template_id" type="string">Meta remote ID.</ResponseField>
    <ResponseField name="name" type="string">Template identifier name.</ResponseField>
    <ResponseField name="language" type="string">Language tag (e.g. `en_US`).</ResponseField>
    <ResponseField name="category" type="string">Category (`MARKETING`, `UTILITY`, `AUTHENTICATION`).</ResponseField>
    <ResponseField name="status" type="string">Review status (`APPROVED`, `PENDING`, `REJECTED`).</ResponseField>
    <ResponseField name="components" type="object[]">Array of component structures.</ResponseField>
    <ResponseField name="quality_score" type="string">Quality rating (`GREEN`, `YELLOW`, `RED`).</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
    <ResponseField name="updated_at" type="string">Last modification timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.sayvy.ai/api/v1/templates?limit=20&page=1" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.sayvy.ai/api/v1/templates"

params = {
    "limit": 20,
    "page": 1
}

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.get(url, params=params, headers=headers)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.sayvy.ai/api/v1/templates?limit=20&page=1", {
  method: "GET",
  headers: {
    "Authorization": "Bearer <token>"
  }
});

const data = await response.json();
console.log(data);
```

```java Java
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.sayvy.ai/api/v1/templates?limit=20&page=1"))
    .header("Authorization", "Bearer <token>")
    .GET()
    .build();

HttpResponse<String> response =
    HttpClient.newHttpClient().send(request, HttpResponse.BodyHandlers.ofString());
```
