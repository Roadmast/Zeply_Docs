---
title: "Cancel campaign"
sidebarTitle: "Cancel campaign"
api: "POST /api/v1/campaigns/{campaign_id}/cancel"
description: "Permanently terminate an in-flight, paused, or scheduled outbound campaign"
---

Permanently cancel a campaign that is currently `scheduled`, `sending`, or `paused`. If scheduled in TaskIQ, its background schedule is un-registered from Redis. In-flight messages that have already been sent to WhatsApp will complete, but no further recipients in the queue will be processed.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="campaign_id" type="string" required>
  Unique UUID identifier of the campaign to cancel. Example: `e4a2e584-3672-4d69-b541-6e9f1a238491`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

Returns the updated [CampaignResponse](/api-reference/campaigns/get-campaign#response-fields) object with status changed to `cancelled`.

<ResponseField name="id" type="string">
  UUID of the cancelled campaign.
</ResponseField>

<ResponseField name="status" type="string">
  Operational status: `cancelled`.
</ResponseField>

<ResponseField name="total_contacts_count" type="number">
  Total contacts originally queued.
</ResponseField>

<ResponseField name="sent_count" type="number">
  Messages dispatched prior to cancellation.
</ResponseField>

<ResponseField name="failed_count" type="number">
  Count of failed deliveries.
</ResponseField>
