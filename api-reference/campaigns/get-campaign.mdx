---
title: "Get campaign"
sidebarTitle: "Get campaign"
api: "GET /api/v1/campaigns/{campaign_id}"
description: "Retrieve complete campaign configuration, audience parameters, and live broadcast delivery telemetry"
---

Retrieve details for a specific outbound campaign by its unique UUID identifier, including current dispatch status, template configuration, audience parameters, and live aggregate delivery counts.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="campaign_id" type="string" required>
  Unique UUID identifier of the campaign. Example: `e4a2e584-3672-4d69-b541-6e9f1a238491`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="id" type="string">
  Unique UUID identifier of the campaign.
</ResponseField>

<ResponseField name="organization_id" type="string">
  UUID of the organization owning the campaign.
</ResponseField>

<ResponseField name="name" type="string">
  Campaign title.
</ResponseField>

<ResponseField name="status" type="string">
  Operational state of the campaign (`draft`, `scheduled`, `sending`, `paused`, `completed`, `cancelled`).
</ResponseField>

<ResponseField name="whatsapp_phone_number_id" type="string">
  UUID of the WhatsApp Business telephone channel.
</ResponseField>

<ResponseField name="message_template_id" type="string">
  UUID of the approved WhatsApp template used, or `null`.
</ResponseField>

<ResponseField name="audience_type" type="string">
  Targeting strategy used (`all`, `tags`, or `manual`).
</ResponseField>

<ResponseField name="audience_tags" type="string[]">
  Array of tags targeted if `audience_type` is `tags`, otherwise `null`.
</ResponseField>

<ResponseField name="audience_contact_ids" type="string[]">
  Array of contact IDs targeted if `audience_type` is `manual`, otherwise `null`.
</ResponseField>

<ResponseField name="scheduled_at" type="string">
  ISO 8601 scheduled start timestamp in UTC, or `null`.
</ResponseField>

<ResponseField name="total_contacts_count" type="number">
  Total number of contacts resolved for this campaign batch.
</ResponseField>

<ResponseField name="sent_count" type="number">
  Count of messages dispatched to the WhatsApp API.
</ResponseField>

<ResponseField name="delivered_count" type="number">
  Count of messages confirmed delivered to recipient handsets.
</ResponseField>

<ResponseField name="read_count" type="number">
  Count of messages read by recipient contacts.
</ResponseField>

<ResponseField name="failed_count" type="number">
  Count of messages that resulted in delivery failure or bounced.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of campaign creation.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last status or metric update.
</ResponseField>
