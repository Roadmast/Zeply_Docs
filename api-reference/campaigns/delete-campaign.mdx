---
title: "Delete campaign"
sidebarTitle: "Delete campaign"
api: "DELETE /api/v1/campaigns/{campaign_id}"
description: "Permanently delete an outbound campaign and purge associated broadcast records"
---

Permanently remove an existing campaign. If the campaign is currently scheduled in TaskIQ, its background schedule is cancelled and unlinked from Redis. All child message delivery records are deleted via database cascade.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Input parameters

<ParamField path="campaign_id" type="string" required>
  Unique UUID identifier of the campaign to delete. Example: `e4a2e584-3672-4d69-b541-6e9f1a238491`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

---

### Response Fields

<ResponseField name="message" type="string">
  Confirmation message: `"Campaign deleted successfully"`.
</ResponseField>

---

<RequestExample>

```bash cURL
curl -X DELETE "https://api.pingr.ai/api/v1/campaigns/e4a2e584-3672-4d69-b541-6e9f1a238491" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/campaigns/e4a2e584-3672-4d69-b541-6e9f1a238491"

headers = {
    "Authorization": "Bearer <token>"
}

response = requests.delete(url, headers=headers)
print(response.status_code)
print(response.json())
```

```javascript JavaScript

    "Authorization": "Bearer <token>"
```

