# Webhooks API Reference

The **Webhooks API** enables you to programmatically manage external HTTPS webhook subscriptions. Register callback URLs to receive immediate alerts for call events, conversational messaging, lead generation, ticket routing, and campaign completion.

## Quick Example: Creating a Webhook

```bash
curl -X POST "https://api.sayvy.ai/api/v1/webhooks" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/api/webhooks/sayvy",
    "events": ["call.completed", "message.received"]
  }'
```
