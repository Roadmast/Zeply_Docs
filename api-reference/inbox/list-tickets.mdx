---
title: "List tickets"
sidebarTitle: "List tickets"
api: "GET /api/v1/inbox/tickets"
description: "Retrieve a paginated list of conversation tickets filtered by status or contact ID"
---

Retrieve conversation tickets for your active organization. Results can be filtered by ticket status (`open` or `closed`) or restricted to a specific contact ID.

---

### Authentication

This endpoint requires Bearer token authentication.

```http
Authorization: Bearer <token>
```

| Header | Type | Required | Description | Format |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | `string` | **Yes** | Scoped organization API key or Bearer JWT token | `Bearer <token>` |

---

### Query Parameters

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer <token>`.
</ParamField>

<ParamField query="status" type="string">
  Filter tickets by state. Allowed values: `open`, `closed`.
</ParamField>

<ParamField query="contact_id" type="string">
  Filter tickets associated with a specific contact UUID.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of tickets to retrieve (1 to 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of tickets to skip for pagination (minimum `0`).
</ParamField>

---

### Response Fields

<ResponseField name="total" type="integer">
  Total number of tickets matching query criteria.
</ResponseField>

<ResponseField name="page" type="integer">
  Computed page number based on offset and limit.
</ResponseField>

<ResponseField name="size" type="integer">
  Batch size returned.
</ResponseField>

<ResponseField name="inboxes" type="object[]">
  Array of ticket objects.

  <Expandable title="InboxResponse Fields">
    <ResponseField name="id" type="string">
      UUID of the inbox ticket.
    </ResponseField>
    <ResponseField name="organization_id" type="string">
      UUID of the owning organization.
    </ResponseField>
    <ResponseField name="contact_id" type="string">
      UUID of the contact.
    </ResponseField>
    <ResponseField name="whatsapp_phone_number_id" type="string">
      UUID of the assigned WhatsApp phone number, or `null`.
    </ResponseField>
    <ResponseField name="status" type="string">
      Ticket state (`open` or `closed`).
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 last update timestamp.
    </ResponseField>
    <ResponseField name="contact" type="object">
      Contact profile brief (name, phone number, tags).
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.pingr.ai/api/v1/inbox/tickets?status=open&limit=25&offset=0" \
  -H "Authorization: Bearer <token>"
```

```python Python
import requests

url = "https://api.pingr.ai/api/v1/inbox/tickets"
headers = {
    "Authorization": "Bearer <token>"
}
params = {
    "status": "open",
    "limit": 25,
    "offset": 0
}

response = requests.get(url, headers=headers, params=params)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.pingr.ai/api/v1/inbox/tickets?status=open&limit=25&offset=0", {
  method: "GET",
  headers: {
    "Authorization": "Bearer <token>"
  }
});

const data = await response.json();
console.log(data);
```
