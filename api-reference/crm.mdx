# CRM API Reference

The **CRM API** enables you to query aggregated customer pipeline performance, manage follow-up tasks linked to customer records, monitor AI vs human conversation handling, and coordinate team task assignments.

## Quick Example: Creating a Follow-Up Task

```bash
curl -X POST "https://api.sayvy.ai/api/v1/crm/tasks" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": "7b8f9e2a-4c1d-48ef-9123-bcde456789ab",
    "title": "Send contract proposal",
    "description": "Client requested proposal with annual volume discount",
    "due_at": "2026-10-15T17:00:00Z"
  }'
```
